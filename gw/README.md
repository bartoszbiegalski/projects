# GML++

Library in C++ for parsing gml-files and for extracting data from it

## Used libraries

* libxml++-2.6 - parsing gml's
* TinyXML2 - XMLDocument object, creating map of namespaces

## Mechanics:
We want to parse .gml file. To do so, we would like to:
* get all namespaces
